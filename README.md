# Charge-On Construction

Architectural preview for review. Build with `npm run build`, then serve `site/` with `npm run preview`. The checked-in HTML also works on static hosting at a subdirectory.

Company information and the four service scopes are in `src/content.json`. The Work gallery and Scope List lead to individual service pages. Ethos presents the construction approach. Practice covers services and the Central Florida service area. The inquiry form prepares a draft in the visitor’s email application for review and sending.

The nine architectural images were created for the earlier Charge-On preview. They are illustrative and do not depict completed Charge-On projects. The preview carries noindex directives.
